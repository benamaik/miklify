# Сторонние компоненты

Код Miklify распространяется по лицензии MIT (см. `LICENSE`). В сборку входят компоненты других авторов со своими лицензиями:

| Компонент | Для чего | Лицензия |
|---|---|---|
| [Electron](https://github.com/electron/electron) | оболочка приложения | MIT, лицензии Chromium лежат рядом с программой (`LICENSES.chromium.html`) |
| [music-metadata](https://github.com/Borewit/music-metadata) | чтение тегов | MIT |
| [Chromaprint / fpcalc](https://github.com/acoustid/chromaprint) | отпечаток звука для распознавания | см. файл LICENSE в репозитории проекта |

Сервисы, которые использует Miklify, работают по своим условиям: YouTube API Services, Jamendo, Radio Browser, AcoustID, MusicBrainz, Cover Art Archive. Музыка из Jamendo распространяется под лицензиями Creative Commons, у каждого трека своя.
